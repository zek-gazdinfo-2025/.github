Üdvözlünk a szervezetünk GitHub oldalán! Csapatunk a modern szoftverfejlesztési módszertanokat (CI/CD, Feature-Branch workflow, Clean Architecture) követve épít mikroszolgáltatás-kész, robusztus vállalatirányítási hátteret napelem-telepítési projektek koordinálására.

---

### 🚀 Zászlóshajó projektünk: [`Napelem-erp`](https://github.com/zek-gazdinfo-2025/Napelem-erp)

A rendszer magja egy modern Python/FastAPI alapú háttérmotor, amely teljes körűen lefedi a napelemes beruházások folyamatait:

* 📦 **240 rekeszes raktárhálózat:** 3D koordináta-alapú rekeszkezelés (`S1-O1-SZ1`), túlcsordulás- és kapacitásvédelemmel, vizuális raktártérképpel.
* ⚙️ **7 fázisú projekt-állapotgép:** Szigorú érvényesítésű életciklus-kezelés és tranzakció-biztos alkatrészallokáció (`allocated` vs. `reserved`).
* 🔒 **Szerepkör-alapú hozzáférés (RBAC):** Biztonságos autentikáció (sózott SHA-256) és elkülönített feladatkörök (Adminisztrátor, Szakember, Raktárvezető, Raktáros).
* 📊 **Pénzügyi kalkuláció és audit:** Valós idejű anyagköltség- és munkadíjszámítás, eseménynapló az átfutási idők követésére.
